Setup Guide

Documentation for acquiring necessary credentials.

1. Google Gemini API

The core neural engine driving casper's reasoning.

  • Visit the Google AI Studio.
  • Click Create API key.
  • Paste it into the Configurations tab.

2. LiveKit Cloud

Powers the low-latency voice architecture.

  • Sign up at LiveKit Cloud.
  • Create a project and navigate to Settings > Keys.
  • Add a new key and copy the URL, API Key, and API Secret.

3. Mem0 Platform

Provides persistent long-term memory across sessions.

  • Sign in to the Mem0 Platform.
  • Generate a new API key from your dashboard.

4. Gmail App Passwords

Allows casper to send and receive emails on your behalf.

  • Go to your Google Account Security settings.
  • Ensure 2-Step Verification is on.
  • Create an App Password.
