# YouTube Search vs Play - Usage Guide

## 🔍 Search (Show Results Only)

Use these commands to **see search results** without auto-playing:

```
"Search for Python tutorials on YouTube"
"Find cat videos on YouTube"
"Show me cooking recipes on YouTube"
"Look for JavaScript tutorials"
"Search YouTube for music videos"
```

**Result:** Opens YouTube search page with results, you can browse and click what you want.

---

## ▶️ Play (Auto-play First Result)

Use these commands to **automatically play** the first result:

```
"Play Python tutorial on YouTube"
"Play Bohemian Rhapsody on YouTube"
"Play cat videos"
```

**Result:** Searches AND automatically clicks first video to play.

---

## 🎯 How It Detects

### **SEARCH (show results):**
- Contains: "search", "find", "look for", "show"
- Does NOT contain: "play"
- Example: "search for cats" → Shows results page

### **PLAY (auto-play):**
- Contains: "play"
- Example: "play cats" → Plays first result

---


## 🎬 Complete YouTube Commands

```bash
# Search & Navigation
"Search for [query]"                   → Show results only
"Play [query]"                         → Search & auto-play first
"Open YouTube"                         → Go to homepage

# Playback Control
"Pause this video"                     → Pause
"Mute the video"                       → Mute
"Unmute"                              → Unmute
"Go fullscreen"                        → Fullscreen

# Ad Management
"Skip this ad"                         → Skip ad instantly
```
